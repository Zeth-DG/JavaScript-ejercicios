# JavaScript-ejercicios

En esta carpeta se subirán los ejercicios realizados en clase o como tarea. 

En estos ejercicios hicimos un repaso de funciones, tipos de datos primitivos y estructuras de datos, enfocándonos en arreglos, bucles y métodos de array. 

Prácticamos escribir funciones comunes y funciones flecha, además de los mejores casos para usar cada tipo. 
En el caso de las funciones flecha, tienen la ventaja de ser más cortas y usadas para acciones sencillas. 
Mientras que las funciones comunes se recomiendan para funciones complejas. 

Vimos un repaso de tipos de datos que podemos declarar, que son: 
- Numeros
- Cadenas
- Booleanos
- Arrays
- Objetos 
- Nulos 

Las mejores opciones para declarar variables dependiendo del tipo de dato: 
- let
- const
- var (que no debe usarse dado que no respeta el scope)

Vimos el scope de las variables que puede ser global, local o solo funcionar en el bloque donde se menciona. 

Además de seguir fomentando el uso de las buenas prácticas durante la realización de nuestro código además de seguir las reglas recomendadas.
